Arduino Experiment No. 2

Servo Motor Control

Aim Components Connections Working Procedure Code Output

Aim

To control the angular position of a servo motor using an Arduino and rotate the servo motor to 0°, 90° and 180° positions.

About the Experiment

In this experiment, a servo motor is controlled using an Arduino.

The servo motor is connected to Arduino digital pin 9. The Arduino sends position commands to move the servo motor to different angles.

The servo first moves to 0°, then to 90°, and finally to 180°. A delay of one second is provided between each movement.

Procedure

  1. Connect the Arduino UNO to the computer using the USB cable.
  2. Connect the servo motor signal wire to Arduino digital pin 9.
  3. Connect the servo VCC wire to 5V.
  4. Connect the servo GND wire to Arduino GND.
  5. Open Arduino IDE.
  6. Go to Tools → Board and select Arduino UNO.
  7. Go to Tools → Port and select the correct COM port.
  8. Enter the Servo Motor Control program.
  9. Click Verify to compile the program.
  10. Click Upload to upload the program to the Arduino.
  11. Observe the movement of the servo motor.

Arduino Code

Servo_Motor_Control.ino 
#include <Servo.h> // Include Servo library

Servo myservo; // Create servo object

void setup() {

    myservo.attach(9); // Attach servo signal pin to Arduino pin 9

}

void loop() {

    myservo.write(0); // Rotate servo to 0 degree

    delay(1000); // Wait for 1 second


    myservo.write(90); // Rotate servo to 90 degree

    delay(1000); // Wait for 1 second


    myservo.write(180); // Rotate servo to 180 degree

    delay(1000); // Wait for 1 second

}

Code Explanation

#include <Servo.h>

Includes the Arduino Servo library required to control the servo motor.

Servo myservo;

Creates a servo object named myservo.

myservo.attach(9);

Connects the servo object to Arduino digital pin 9.

myservo.write(0);

Commands the servo motor to move to the 0° position.

myservo.write(90);

Commands the servo motor to move to the 90° position.

myservo.write(180);

Commands the servo motor to move to the 180° position.

delay(1000);

Pauses the program for 1000 milliseconds, which is equal to 1 second.

Expected Output

  • Servo motor moves to 0°.
  • Servo remains at 0° for 1 second.
  • Servo motor moves to 90°.
  • Servo remains at 90° for 1 second.
  • Servo motor moves to 180°.
  • Servo remains at 180° for 1 second.
  • The sequence repeats continuously.

Result

The servo motor angle control experiment was successfully implemented using Arduino. The servo motor moves to 0°, 90° and 180° with a delay of one second between each position.
